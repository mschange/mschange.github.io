9.2 继承（38）

核心思想： 子类自动拥有父类的属性和方法，实现代码复用；子类可以扩展或覆盖（override）父类行为。

基本语法

关键概念

概念 说明
super().__init__() 调用父类的构造方法，必须写在子类 __init__ 中
方法重写（Override） 子类定义与父类同名的方法，覆盖父类行为
isinstance(obj, cls) 判断对象是否是某类（或其子类）的实例
issubclass(A, B) 判断 A 是否是 B 的子类

9.3 多继承与 MRO（39）

核心思想： 一个子类同时继承多个父类；Python 用 C3 线性化算法（MRO） 确定方法查找顺序。

Mixin 模式 — 功能组合

MRO 方法解析顺序

菱形继承与 super() 协作

9.4 多态（40）

核心思想： 同一个接口，不同的类有不同的实现；调用方无需关心对象的具体类型。

方式一：抽象基类（ABC）

抽象基类的特点：

  • 使用 ABC 和 @abstractmethod 定义
  • 抽象类不能直接实例化，会报 TypeError
  • 子类必须实现所有抽象方法，否则也不能实例化

方式二：鸭子类型（Duck Typing）

鸭子类型哲学： “如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子。”

  • Member — 抽象基类 + 继承（RegularMember / VipMember）
  • Library — 业务控制器（协调 Book 和 Member 的交互）

10.2 Book 类

设计要点：

  • __stock 是私有属性，外部无法直接修改
  • stock 是只读的 @property，只能看不能改
  • 借书/还书通过方法控制，内部做库存校验

10.3 Member 类体系

继承关系：

多态体现： borrow_book() 中调用 self.max_borrow()，具体行为由子类决定。

10.4 Library 类

设计要点：

  • __current 追踪当前登录用户，所有操作需要先登录
  • _require_login() 是内部辅助方法，检查登录状态
  • 使用 try/except 处理库存不足等业务异常

原则 说明
