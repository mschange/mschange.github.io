十一、常见错误与调试

11.1 常见错误

错误 原因 解决方案
更新后返回旧数据 没有 refresh() 使用 await session.refresh(book)
PATCH 把字段设为 None 用了 model_dump() 使用 exclude_unset=True
批量更新不生效 没有 commit await session.commit()
404 错误 书籍不存在 先 session.get() 检查

11.2 model_dump 方法对比

方法 行为 适用场景
model_dump() 返回所有字段 PUT 全量更新
model_dump(exclude_unset=True) 只返回客户端传的字段 PATCH 部分更新
model_dump(exclude_none=True) 排除值为 None 的字段 特殊场景
model_dump(exclude_defaults=True) 排除默认值的字段 特殊场景

十二、关键要点总结

知识点 说明 核心代码
PUT 全量更新 所有字段必须传递 book_data.model_dump()
PATCH 部分更新 只传需要修改的字段 model_dump(exclude_unset=True)
exclude_unset 只获取用户传递的字段 exclude_unset=True
setattr 动态更新 循环设置属性 setattr(book, key, value)
业务验证 更新前检查业务规则 if new_price > old_price * 3:
批量更新 SQLAlchemy update() update(Book).where(...).values(...)
批量状态更新 修改多个记录的状态 update().values(is_active=0)
refresh 更新后刷新对象 await session.refresh(book)
rowcount 受影响的行数 result.rowcount
涨价计算 百分比转乘数 multiplier = 1 + percent / 100

十三、课后练习

  1. 基础：实现一个 PATCH 接口，只更新书籍的 description 字段
  2. 进阶：实现批量更新库存接口，将某分类下所有书籍库存设为指定值
  3. 挑战：实现一个更新接口，记录每次更新前的旧值（审计日志）
