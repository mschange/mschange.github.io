Step 1：Path() 基础 —— 路径参数数值验证

为什么需要 Path()？

默认情况下，路径参数只做类型转换（str → int），不做数值验证。
使用 Path() 可以添加 ge（>=）、le（<=）、gt（>）、lt（<）等约束。

参数 类型 说明

常见错误与排查

错误现象 原因 解决方案
422 Unprocessable Entity 参数验证失败 检查参数格式和范围
404 Not Found 路径参数格式错误 检查 URL 路径
alias 参数不生效 使用了原始参数名 URL 中必须使用 alias 名
列表参数只得到一个值 没有用 list[type] 类型注解改为 list[str]

关键要点总结

要点 说明
Path() 用于路径参数验证，支持 ge/le/pattern 等
Query() 用于查询参数验证，支持默认值和列表
Annotated Python 3.9+ 的类型注解语法
pattern 正则表达式验证字符串格式
alias 参数别名，URL 中使用别名而非函数参数名
deprecated 标记废弃参数，Swagger UI 显示删除线
examples 为 Swagger UI 提供示例值
必选参数 不设默认值的 Query() 参数即为必选
列表参数 类型注解为 list[str]，URL 中多次传同名参数
