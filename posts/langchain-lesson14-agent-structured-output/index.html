二、三种响应策略（Response Strategy）

2.1 策略总览

2.2 ProviderStrategy —— 模型原生结构化输出

使用模型提供商的原生结构化输出功能实现结构化输出。

“原生结构化输出”指的是 LLM 提供商通过 API 直接提供的、在模型响应阶段就强制保证输出格式符合预定规范的能力，在模型生成内容的源头确保结构化准确性。

适用于支持原生结构化输出的模型，比如 OpenAI、Anthropic Claude 或 xAI Grok 等。

2.3 ToolStrategy —— 工具调用方式

对于不支持原生结构化输出的模型，LangChain 采用 ToolStrategy 工具调用的方式实现结构化输出。

此策略兼容绝大多数支持工具调用的现代模型，其核心原理是：

  1. 动态创建一个**”虚拟工具”**
  2. 该工具的输入参数对应着期望的数据结构
  3. 当模型需要生成最终答案时，系统引导模型”调用”这个虚拟工具
  4. 从而间接产生符合要求的结构化数据

2.4 AutoStrategy / 直接传入类型 —— 自动选择

当直接传入一个定义类型时，LangChain 会自动包装为 AutoStrategy，触发自动选择策略：

  • 如果模型支持原生结构化输出（如 OpenAI、Anthropic Claude），则优先使用 ProviderStrategy
  • 否则使用 ToolStrategy

版本说明：在 LangChain 1.0 及以上版本中，直接传递模式（如 response_format=ContractInfo）不再支持，必须显式使用 ToolStrategy 或 ProviderStrategy。经过测试，目前 LangChain 1.2 版本还可使用直接传入方式。

2.5 三种策略对比

对比项 ProviderStrategy ToolStrategy AutoStrategy（直接传入）
原理 模型原生能力 虚拟工具调用 自动选择
兼容性 仅支持原生结构化输出的模型 兼容绝大多数模型 取决于模型
可靠性 最高（源头保证） 高（工具调用机制） 自动适配
显式程度 显式指定 显式指定 隐式（自动推断）
适用模型 OpenAI / Claude / Grok DeepSeek / 大部分现代模型 任意

三、ToolStrategy + 五种 Schema 定义方式

3.1 Pydantic BaseModel

最推荐的方式，功能最全，支持字段描述、默认值、可选字段、枚举约束等。

返回值：Pydantic 对象，用 . 访问属性。

3.2 TypedDict + Annotated

轻量方式，不需要 Pydantic，用 Annotated 为字段添加描述。

返回值：dict，用 [] 访问。

3.3 JSON Schema 字典

最灵活的方式，适合已有 JSON Schema 或从外部导入的场景。

注意：JSON Schema 字典必须有 "title" 字段，否则 LangChain 无法将其转换为工具名称。

返回值：dict，用 [] 访问。

3.4 @dataclass

使用 Python 标准库，轻量但功能有限。

注意：

  • @dataclass 的字段描述用 field(metadata={"description": "..."})，不是 Pydantic 的 Field(description=...)
  • @dataclass 不支持 Literal 枚举约束
  • 在 ToolStrategy 中，@dataclass 返回的是 dataclass 对象

八、常见问题

Q1：response_format=ContractInfo 和 response_format=ToolStrategy(ContractInfo) 有什么区别？

  • 直接传入 ContractInfo：LangChain 自动包装为 AutoStrategy，根据模型能力自动选择 ProviderStrategy 或 ToolStrategy
  • 显式传入 ToolStrategy(ContractInfo)：强制使用工具调用方式

在当前版本（LangChain 1.2）中两种方式都可以使用，但建议显式使用策略以获得更可控的行为。

Q2：ProviderStrategy 和 ToolStrategy 应该选哪个？

场景 推荐策略
使用 OpenAI / Claude 等支持原生结构化输出的模型 ProviderStrategy
使用 DeepSeek 等其他模型 ToolStrategy
不确定模型支持哪种 直接传 Schema（AutoStrategy 自动选择）

Q3：tool_message_content 会影响 structured_response 吗？

不会。tool_message_content 只影响对话历史中的 ToolMessage 内容，结构化数据始终正确存入 result["structured_response"]。

Q4：Union 多 Schema 时，模型怎么选择用哪个？

模型会根据用户输入的内容语义自动判断。例如：

  • 输入包含姓名/邮箱/电话 → 选择 ContactInfo
  • 输入包含事件/日期 → 选择 EventInfo
