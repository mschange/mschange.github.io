一、用户模块功能清单

功能 接口 方法 认证 说明
用户注册 /api/user/register POST 否 创建用户、生成 Token
用户登录 /api/user/login POST 否 验证密码、生成 Token
获取用户信息 /api/user/info GET 是 Token 认证后返回用户信息
更新用户信息 /api/user/update PUT 是 修改昵称、头像等
修改密码 /api/user/password PUT 是 验证旧密码、更新新密码

  1. 用户注册：密码加密、生成 Token
  2. 用户登录：验证密码、生成 Token

  5. 更新用户信息：部分更新（只更新传的字段）
