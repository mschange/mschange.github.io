一、invoke 的三种传参方式

LangChain 的 invoke 方法支持三种输入类型，适用于不同场景。

1.1 传入字符串

最简单的方式，直接传入文本，LangChain 自动将其转为 HumanMessage。

1.2 传入消息对象列表

使用 SystemMessage、HumanMessage、AIMessage 等消息对象，可以精确控制对话角色和上下文。

1.3 传入字典

以字典形式传递，messages 的值可以是原始字典列表（role + content），适合从 JSON 或外部接口传入。

对比总结

方式 适用场景 灵活性
字符串 快速测试、单轮对话 低
消息对象列表 多轮对话、需要 SystemMessage 高
字典 从 JSON/接口传入、Agent 调用 高

二、模型初始化参数详解

init_chat_model 支持多种参数来控制模型行为，理解它们的区别很重要。

2.1 标准参数 vs model_kwargs vs extra_body

优先级与使用场景：

参数 用途 示例
标准参数（顶层） 通用采样参数 temperature=0.7, max_tokens=500
model_kwargs 模型特定的采样参数 top_k, min_p, repetition_penalty
extra_body 非标准功能开关 深度思考、推理模式等

2.2 查看模型元信息

model.profile 返回模型的元数据字典，包含：

  • max_input_tokens / max_output_tokens：上下文窗口大小
  • text_inputs / image_inputs：支持的输入类型
  • tool_calling / structured_output：是否支持工具调用和结构化输出
  • reasoning_output：是否支持推理输出
