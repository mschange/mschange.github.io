七、Few-Shot：通过示例教模型回答问题

7.1 什么是 Few-Shot

Few-Shot（少样本学习）是一种提示词技巧：在 system prompt 中提供几个输入-输出示例，让模型学习回答的风格和模式，然后按照同样的方式回答新问题。

7.2 为什么需要 Few-Shot

有些时候，我们希望模型按照固定的风格来回答，但这种风格又不太好描述。与其用大量文字解释”你应该怎么写”，不如直接给几个例子让模型自己学。

方式 说明 适用场景
直接描述风格 “请用诗意、科幻的语言…” 风格容易用文字描述
Few-Shot 示例 给 2-3 个输入-输出示例 风格难以描述，但可以通过例子体现

Few-Shot 的优势：

  • 无需精确描述风格，例子本身就是最好的说明
  • 模型能学到隐含的模式（格式、语气、长度、创意程度）
  • 简单有效，不需要额外训练

Q1: PromptTemplate 和 ChatPromptTemplate 有什么区别？

对比项 PromptTemplate ChatPromptTemplate
返回值 纯字符串 消息列表
角色支持 无 system / human / ai
适用场景 简单文本模板 多角色对话
与模型配合 model.invoke(string) model.invoke(messages)

建议： 与大模型对话时，优先使用 ChatPromptTemplate，因为它能正确设置消息角色。

PromptValue 是 LangChain 的内部包装对象，包含生成的提示词内容。
