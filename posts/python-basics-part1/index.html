生成器 vs 列表对比：

对比项 列表 生成器
语法 [x for x in range(n)] (x for x in range(n)) 或 yield
内存 一次性加载全部数据 按需生成，占用极小
取值 可索引 lst[0] 只能逐个 next()
遍历 可多次遍历 只能遍历一次（耗尽即空）
适用场景 数据量小、需要随机访问 数据量大、只需顺序访问
