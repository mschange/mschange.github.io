一、浏览历史模块功能清单

功能 接口 方法 认证 说明
添加浏览记录 /api/history/add POST 是 重复浏览则更新时间
获取浏览历史 /api/history/list GET 是 分页、包含新闻详情
删除单条记录 /api/history/delete/{id} DELETE 是 删除指定记录
清空浏览历史 /api/history/clear DELETE 是 删除所有记录

二、与收藏模块的区别

对比项 收藏模块 浏览历史模块
唯一约束 有（不能重复收藏） 无（可以重复浏览）
重复操作 报错 更新时间
记录时机 用户主动收藏 用户浏览新闻时自动记录
业务含义 用户想看的 用户看过的

重复浏览处理

为什么这样设计？

  • 收藏：用户主动行为，重复收藏没有意义 → 唯一约束
  • 浏览：被动行为，重复浏览表示「又看了一次」→ 更新时间

十一、本文档总结

11.1 实现了什么

  1. 添加浏览记录：重复浏览更新时间
  2. 浏览历史列表：联表查询，包含新闻详情
  3. 删除单条记录：路径参数
  4. 清空浏览历史：批量删除

11.2 与收藏模块对比

功能 收藏 浏览历史
重复操作 报错（唯一约束） 更新时间
删除接口 /remove?newsId=1 /delete/{history_id}
参数类型 查询参数（newsId） 路径参数（history_id）

十二、项目完成总结

12.1 已实现的功能

  1. 用户模块：注册、登录、认证、信息更新、密码修改
  2. 新闻模块：分类列表、新闻列表、新闻详情、相关推荐
  3. 收藏模块：检查、添加、取消、列表、清空
  4. 浏览历史模块：添加、列表、删除、清空

12.2 技术栈

  • FastAPI + Uvicorn
  • SQLAlchemy 2.0（异步）
  • MySQL 8.0
  • passlib + bcrypt（密码加密）
  • Pydantic（数据校验）
