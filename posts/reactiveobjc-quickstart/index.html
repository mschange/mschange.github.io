ReactiveObjC 是什么？

ReactiveObjC（常简称 RAC）是 Objective-C 生态中的响应式编程框架，源自 ReactiveCocoa。它把事件、异步回调和数据流统一成 信号（Signal），让你用声明式的方式组合业务逻辑。

适合处理：

  • UI 事件与数据绑定
  • 网络请求串联 / 并行
  • 复杂状态流转与取消

核心概念

Signal（信号）

信号是事件的序列，可以发送三种事件：

  1. next — 正常值
  2. error — 错误并终止
  3. completed — 成功结束

Subject

RACSubject 既是信号，也是订阅者，常用于把命令式回调桥接到响应式流。

Command

RACCommand 适合封装「用户操作 → 异步任务」这一类可执行单元，例如按钮点击后发起请求。

学习建议

  1. 先搞清 subscribeNext / error / completed 生命周期
  2. 熟悉常用操作符：map、filter、combineLatest、flattenMap、throttle
  3. 注意线程切换：deliverOnMainThread / subscribeOn
  4. 管理订阅生命周期，避免循环引用（@weakify / @strongify）

小结

ReactiveObjC 的价值在于：用数据流描述变化，用操作符组合逻辑。入门时不必一次吃透全部操作符，从 UI 绑定和简单异步串联开始，很快就能感受到它在复杂页面中的优势。
