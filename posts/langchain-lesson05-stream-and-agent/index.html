一、模型调用方式概览

LangChain 提供多种模型调用方式：

方法 类型 说明 返回值
invoke() 同步非流式 等待完整响应 AIMessage
stream() 同步流式 逐块返回 Generator[AIMessageChunk]
ainvoke() 异步非流式 异步等待完整响应 AIMessage
astream() 异步流式 异步逐块返回 AsyncGenerator[AIMessageChunk]
batch() 批量 并发处理多个输入 List[AIMessage]

七、Agent 基础概念

7.1 什么是 Agent

Agent（智能体）是一个能够：

  • 理解用户意图
  • 规划执行步骤
  • 调用工具完成任务
  • 根据反馈调整策略

Agent = 模型 + 工具 + 推理能力

7.2 Agent 与普通模型的区别

维度 普通模型 Agent
能力 只能生成文本 可以调用工具、执行操作
输入 文本 文本 + 工具描述
输出 文本 文本 + 工具调用
推理 单步 多步推理
状态 无状态 有状态（消息历史）
