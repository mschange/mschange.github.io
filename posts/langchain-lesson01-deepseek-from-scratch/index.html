六、两种方案对比

对比项 方案一：显式传入 方案二：自动读取
代码行数 多 2 行（手动 os.getenv） 少，更简洁
api_key 手动传 api_key=DEEPSEEK_API_KEY 不传，自动从环境变量发现
api_base 手动传 api_base=DEEPSEEK_BASE_URL 不传，自动发现或使用默认值
灵活性 高，可动态指定不同的 Key 一般，依赖固定变量名
适用场景 多 Key 切换、动态配置 日常开发推荐
可读性 参数来源一目了然 需要知道自动发现规则

选择建议：

  • 日常开发、单 Key → 方案二（自动读取）
  • 需要切换多个 Key、从数据库/配置中心读取 → 方案一（显式传入）

参数 对应环境变量 默认值 说明

九、常见问题

9.1 ModuleNotFoundError: No module named ‘langchain_deepseek’

原因： 包未安装，或安装到了错误的 Python 环境。

9.2 AuthenticationError: Invalid API key

原因： API Key 无效或未正确加载。

9.3 ConnectionError

原因： 网络不通或 DEEPSEEK_BASE_URL 配置错误。

确认 .env 中的地址为 https://api.deepseek.com（注意不要多加 /v1）。
