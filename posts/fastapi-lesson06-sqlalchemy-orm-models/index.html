Step 1：定义基类 —— DeclarativeBase

概念

SQLAlchemy 2.0 推荐使用 DeclarativeBase 作为所有模型的基类。所有 ORM 模型都继承自它。

代码示例

为什么用 DeclarativeBase？

特性 说明
声明式映射 通过类定义自动映射到数据库表
类型安全 支持 Python 类型提示
元数据管理 自动管理表的元数据（Base.metadata）
2.0 风格 SQLAlchemy 2.0 推荐方式

UniqueConstraint 复合唯一约束 (user_id, order_no)
CheckConstraint 检查约束 price >= 0

关键要点总结

要点 说明
DeclarativeBase SQLAlchemy 2.0 推荐的模型基类
Mapped[type] 类型注解，声明列的 Python 类型
mapped_column() 定义列的详细属性
default Python 层面的默认值
server_default 数据库层面的默认值
UniqueConstraint 复合唯一约束
CheckConstraint 检查约束（如 price >= 0）
Index 索引定义（单列/复合）
__table_args__ 表级参数（约束、索引、字符集等）
create_all 自动建表（已存在则跳过）
