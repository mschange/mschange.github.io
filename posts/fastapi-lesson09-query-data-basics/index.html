8.1 常见错误

错误 原因 解决方案
MissingGreenlet 在异步代码中触发了懒加载 使用 expire_on_commit=False
NoResultFound scalar_one() 查不到数据 改用 scalar_one_or_none()
返回空列表 过滤条件写错 开启 echo=True 查看 SQL
类型不匹配 查询参数类型与模型不匹配 检查 Query 参数类型
