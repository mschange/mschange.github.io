六种方式对比

循环 add 少量批量 一般 多 一般
add_all 批量数据 较好 少 推荐
bulk_insert_mappings 大量数据 最好 少 大量数据推荐
get-or-create 去重插入 一般 中 特定场景
带默认值 使用模型默认值 一般 少 配合其他方式

常见错误与排查

错误 原因 解决方案
IntegrityError: Duplicate entry 唯一约束冲突 检查 username/email 是否重复
PendingRollbackError 上次事务失败未回滚 在 get_db 中添加 rollback
对象没有 id 没有 commit + refresh 确保调用 await db.commit() 和 await db.refresh()
InvalidRequestError Session 已关闭 确保在 get_db 的 yield 范围内操作

关键要点总结

要点 说明
db.add(obj) 将对象加入会话（pending 状态）
db.add_all([obj1, obj2]) 批量加入会话
await db.commit() 提交事务，执行 INSERT SQL
await db.refresh(obj) 从数据库刷新对象（获取 id 等）
insert(Model).values(...) Core 方式批量插入
select().where(...) 查询是否已存在（get-or-create）
default Python 层面的默认值
server_default 数据库层面的默认值
事务一致性 一个 commit 中的所有操作要么全成功要么全失败
