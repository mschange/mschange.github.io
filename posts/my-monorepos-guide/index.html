  • private: true — 根包不发布到 npm，只作为 workspace 管理入口

第二步：创建 TypeScript 配置

2.1 根 tsconfig.json

关键配置解释：

  • target: ES2020 — 现代浏览器都支持，不需要降级到 ES5
  • moduleResolution: bundler — 配合 Vite 使用，支持 import xxx from './foo.ts' 带扩展名
  • jsx: react-jsx — React 17+ 的新 JSX 转换，不需要手动 import React
  • strict: true — 开启所有严格类型检查
  • paths: @mschange/* — 开发时可以直接 @mschange/xxx 引入源码，不用先 build
  • references — TypeScript 项目引用，加速增量编译

第三步：创建 @mschange/utils（工具函数包）

这是最基础的包，没有 React 依赖，纯 TypeScript 工具函数。

3.1 创建目录结构

3.2 package.json

关键字段解释：

  • main — CommonJS 入口，Node.js 和旧版打包器用这个
  • module — ESM 入口，现代打包器（Vite、Webpack 5+）优先使用，支持 tree-shaking
  • types — TypeScript 类型声明入口
  • exports — Node.js 条件导出，精确控制不同场景下的入口文件
  • sideEffects: false — 告诉打包器”这个包没有副作用”，可以安全 tree-shake
  • files: ["dist"] — 只发布 dist 目录到 npm
  • prepublishOnly — 发布前自动构建，防止忘记 build 就 publish

3.3 tsconfig.json

为什么要覆盖这些选项：

  • composite: true — 启用项目引用模式，让根 tsconfig 可以引用这个子包
  • noEmit: false — 覆盖根的 noEmit: true，因为构建时需要输出文件
  • allowImportingTsExtensions: false — 构建时不允许 .ts 扩展名导入（Vite 会处理）

3.4 vite.config.ts

配置解释：

  • vite-plugin-dts — 构建时自动生成 .d.ts 类型声明文件
  • insertTypesEntry: true — 在 dist 中插入类型入口
  • lib.name: 'MsChangeUtils' — UMD 模式的全局变量名（虽然本项目不用 UMD）
  • formats: ['es', 'cjs'] — 同时输出 ESM 和 CommonJS 两种格式
  • fileName — 自定义输出文件名

关键区别：rollupOptions.external

  • 必须把 react、react-dom、antd 标记为外部依赖

9.4 CI/CD 自动发布（GitHub Actions）

.github/workflows/release.yml

配置 NPM Token

  1. 在 npmjs.com → Access Tokens → 生成一个 Publish token
  2. 在 GitHub 仓库 → Settings → Secrets → New repository secret
  3. Name: NPM_TOKEN，Value: 刚才生成的 token

工作流说明

  • 每次 push 到 main 分支，Changesets Action 会检查是否有未消费的 changeset
  • 如果有 → 创建一个 “Version Packages” PR
  • 合并该 PR → 自动更新版本号 → 构建 → 发布到 npm
  • 整个过程零人工干预

附录 B：核心命令速查

命令 说明
pnpm install 安装所有依赖
pnpm dev 启动文档站开发服务器
pnpm build 构建所有包
pnpm build:docs 构建文档站
pnpm type-check TypeScript 类型检查
pnpm clean 清理所有 dist 和 node_modules
cd packages/xxx && pnpm dev 单包监听模式构建
pnpm changeset 创建版本变更描述
pnpm version 消费 changeset，更新版本号
pnpm release 构建 + 发布到 npm

附录 C：发布前 Checklist

  • pnpm type-check 通过
  • pnpm build 成功
  • 每个包的 dist/ 下有正确的 .js、.esm.js、.d.ts
  • npm pack --dry-run 检查发布文件列表正确
  • 文档站 pnpm dev 能正常预览
  • 所有新组件都有 index.md 文档
  • changeset 已创建
  • npm whoami 确认身份正确

发布时报 402/403

构建产物中包含了 react/antd

检查 vite.config.ts 的 rollupOptions.external 是否包含了所有 peerDependencies。

文档站中组件不渲染

检查 .dumirc.ts 的 alias 是否指向了源码入口（src/index.ts），而不是 dist。
