一、前置知识

1.1 为什么需要异步？

在 Web 开发中，数据库查询、网络请求、文件读写都是 I/O 密集型操作。同步方式下，线程在等待 I/O 时完全空闲，造成资源浪费。

1.2 Python 异步编程基础要求

知识点 重要程度 说明
async def 必须 定义异步函数（协程函数）
await 必须 等待异步操作完成
asyncio.run() 必须 启动事件循环
asyncio.gather() 重要 并发执行多个协程
async with 重要 异步上下文管理器
类型注解 必须 FastAPI 依赖类型注解进行参数验证

7.4 最佳实践总结

规则 说明
所有 I/O 操作都要 await 数据库、网络、文件读写
不要在 async 函数中用同步阻塞 time.sleep → asyncio.sleep
并发任务用独立 Session 不要共享 Session
使用 async with 管理资源 自动关闭会话
expire_on_commit=False commit 后仍可访问属性
异常时 await db.rollback() 确保事务回滚

十、关键要点总结

知识点 说明
create_async_engine 创建异步引擎，使用 mysql+aiomysql 驱动
async_sessionmaker 异步会话工厂，class_=AsyncSession
expire_on_commit=False commit 后属性不过期
async def + await FastAPI 异步路由的基本模式
asyncio.gather() 并发执行多个协程，总耗时 ≈ 最慢的那个
并发写入用独立 Session 不能共享 Session 给多个并发任务
async with 异步上下文管理器，自动管理资源生命周期
await db.rollback() 异常时必须回滚事务
避免同步阻塞 time.sleep → asyncio.sleep
pool_recycle 防止 MySQL 断开空闲连接
