一、create_agent 概览

1.1 什么是 Agent

Agent 是 LangChain 中的自主决策执行器，它能够：

  1. 接收用户输入
  2. 判断是否需要调用工具
  3. 如果需要，自动选择并调用合适的工具
  4. 将工具返回的结果整合后，生成最终回复

1.2 create_agent 函数签名

参数 类型 说明
model BaseChatModel 绑定的 LLM 模型
tools List[BaseTool] 工具列表，默认为空
name str Agent 名称，用于日志、调试、消息标记
system_prompt str / SystemMessage 系统提示词，定义 Agent 的角色和行为

九、常见问题

Q1："message" 和 "messages" 的区别？

Agent 的 invoke 方法要求 key 是 "messages"（复数形式）。如果写成 "message"，模型会收到空消息列表，报错：

Q2：create_agent 不传 tools 有什么用？

不传 tools 时，Agent 等价于模型的包装器，返回格式统一为 {"messages": [...]}。这在需要统一接口处理（后续可能加工具）时很有用。

Q3：system_prompt 和 messages 中的 SystemMessage 会冲突吗？

不会。如果同时使用了 system_prompt 参数和 messages 中的 SystemMessage，两者都会出现在消息列表中。建议只使用其中一种方式，避免重复。

Q4：Agent 会无限循环调用工具吗？

不会。当模型认为工具返回的信息已经足够回答问题时，会生成不带 tool_calls 的 AIMessage，循环自动终止。

Q5：多个工具的执行顺序是怎样的？

当模型返回多个 tool_calls 时，Agent 会并行执行所有工具，然后将所有 ToolMessage 一起传给模型。工具之间没有依赖关系时，并行执行效率更高。

Q7：TavilySearch 搜索不到结果怎么办？

  1. 检查 API Key 是否正确配置
  2. 检查是否超出免费额度
  3. 尝试调整 search_depth="advanced" 获取更深度的搜索结果
  4. 检查网络连接
