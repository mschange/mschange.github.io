一、前置知识

1.1 删除数据的两种方式

在数据库操作中，”删除”有两种截然不同的策略：

方式 说明 可恢复 适用场景
硬删除 直接从数据库中物理删除记录 不可恢复 临时数据、缓存数据
软删除 设置标记字段（如 is_deleted=True） 可恢复 业务数据、用户数据

1.3 前置技术要求

知识点 重要程度 说明
SQLAlchemy ORM 必须 db.delete()、select()
SQLAlchemy Core 重要 delete()、update() 语句
异步操作 必须 await db.execute()、await db.commit()
条件查询 必须 where()、in_()
HTTP DELETE 方法 必须 @app.delete()

十、关键要点总结

知识点 说明
db.delete() ORM 硬删除方式
delete() Core 批量硬删除方式
update().values(is_deleted=True) 批量软删除方式
is_deleted + deleted_at 软删除标记字段
Book.is_deleted == False 查询时过滤已删除记录
恢复操作 将 is_deleted 设回 False
in_() 批量操作：Book.id.in_([1,2,3])
result.rowcount 获取受影响的行数
硬删除不可恢复 适合临时数据
软删除可恢复 适合业务数据（推荐）
