一、前置知识

1.1 什么是响应模型？

响应模型定义了接口返回给客户端的数据结构。它的作用：

  • 字段过滤：只返回需要的字段（隐藏敏感信息）
  • 类型保证：确保返回数据符合预期格式
  • 文档生成：在 Swagger 文档中展示响应示例
