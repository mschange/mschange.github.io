12.1 常见错误

错误 原因 解决方案
验证器不生效 忘记 @classmethod 加上 @classmethod 装饰器
IntegrityError 后连接损坏 没有 rollback except 中先 rollback()
自定义异常返回 500 没注册处理器 @app.exception_handler()
model_validator 报错 mode 参数错误 使用 mode="after"
验证器中访问其他字段 field_validator 限制 改用 model_validator

十三、关键要点总结

知识点 说明 核心代码
Field 验证 基础类型/范围/长度验证 Field(gt=0, min_length=2)
field_validator 单字段自定义验证 @field_validator("title")
model_validator 跨字段综合验证 @model_validator(mode="after")
HTTPException 手动抛出 HTTP 错误 raise HTTPException(status_code=404)
IntegrityError 数据库约束冲突 except IntegrityError: rollback()
自定义异常 封装业务语义 class BookNotFoundException(Exception)
全局异常处理器 统一错误格式 @app.exception_handler()
RequestValidationError Pydantic 验证错误 自定义 422 返回格式
rollback 异常后必须回滚 await session.rollback()
验证顺序 Field → field_validator → model_validator 逐层验证
兜底处理器 捕获所有未处理异常 @app.exception_handler(Exception)
错误码 标识错误类型 "error_code": "BOOK_NOT_FOUND"
