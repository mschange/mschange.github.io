四、Annotated + TypedDict

4.1 基本用法

Annotated 解决了 TypedDict 无法添加字段描述的问题：

Annotated[T, metadata] 的含义：

  • T：字段类型
  • metadata：附加的元数据（这里用作字段描述）

与纯 TypedDict 的区别：

对比项 纯 TypedDict Annotated + TypedDict
字段描述 只有注释 # 姓名 Annotated[str, "姓名"]
模型理解 较弱（注释会被忽略） 较强（描述会传给模型）
提取准确度 一般 更高

使用 Python 标准库 dataclass，语法简洁，不需要第三方依赖：

与 Pydantic 的关键区别：

对比项 Pydantic @dataclass
