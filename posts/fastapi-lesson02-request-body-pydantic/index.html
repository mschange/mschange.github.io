一、前置知识

1.1 什么是请求体？

请求体（Request Body）是客户端发送给服务器的数据，通常是 JSON 格式。

1.2 Pydantic 是什么？

Pydantic 是 Python 的数据验证库，FastAPI 基于它实现：

  • 数据验证：自动检查类型、范围、必填
  • 数据转换：字符串 "89.9" → 浮点数 89.9
  • 数据序列化：Python 对象 → JSON
  • 文档生成：自动生成 Swagger API 文档

1.3 Pydantic v2 vs v1

功能 v1 语法 v2 语法（本课程使用）
模型转字典 model.dict() model.model_dump()
字典转模型 Model.parse_obj(data) Model.model_validate(data)
ORM 模式 orm_mode = True from_attributes = True
字段验证 @validator @field_validator
