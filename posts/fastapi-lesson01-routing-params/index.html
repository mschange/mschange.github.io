一、FastAPI 前置知识

在开始学习 FastAPI 之前，你需要了解以下基础知识：

1.1 Python 基础要求

知识点 重要程度 说明
Python 3.10+ 必须 FastAPI 使用新语法（match、X | Y 类型联合）
类型注解 必须 str, int, List[str], Optional[int]
装饰器 必须 @app.get("/") 就是装饰器
异步编程 重要 async def, await 关键字
字典操作 必须 **dict 解包、.get()、.items()
列表推导式 重要 [x for x in items]
虚拟环境 必须 python -m venv venv

1.5 Web 基础概念

HTTP 方法

方法 用途 幂等性 示例
GET 获取数据 是 获取书籍列表
POST 创建数据 否 新增一本书
PUT 全量更新 是 更新整本书信息
PATCH 部分更新 否 只更新价格
DELETE 删除数据 是 删除一本书

HTTP 状态码

状态码 含义 使用场景
200 OK 请求成功
201 Created 创建成功
204 No Content 删除成功（无返回体）
400 Bad Request 请求参数错误
404 Not Found 资源不存在
422 Unprocessable Entity 数据验证失败
500 Internal Server Error 服务器内部错误

包名 作用
