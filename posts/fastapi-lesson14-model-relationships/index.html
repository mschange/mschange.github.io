一、前置知识

1.1 为什么需要模型关系？

在真实应用中，数据之间往往存在关联关系。例如：

  • 一个出版社出版多本书（一对多）
  • 一本书有多个章节（一对多）
  • 一本书有多个标签，一个标签关联多本书（多对多）

如果不用关系，所有数据都堆在一张表里，会导致大量冗余。关系型数据库通过 外键（ForeignKey） 和 关联表 来建立表与表之间的联系。

1.2 三种基本关系类型

关系类型 说明 实现方式 示例
一对多 A 的一条记录对应 B 的多条记录 ForeignKey + relationship 出版社 → 书籍
多对一 B 的多条记录属于 A 的一条记录 ForeignKey + relationship 书籍 → 出版社
多对多 A 和 B 互相多条关联 关联表 + secondary 书籍 ↔ 标签

五、级联操作（cascade）

5.1 cascade 参数详解

cascade 值 说明
save-update 保存/更新时级联到子对象（默认）
merge merge 时级联到子对象（默认）
delete 删除父对象时级联删除子对象
delete-orphan 子对象脱离父对象时自动删除
all 包含 save-update + merge + delete
all, delete-orphan 最常用：全部级联 + 孤儿删除

7.1 常用加载策略对比

策略 SQL 查询次数 适用场景
selectin 2次（主表1次 + 关联表1次） 异步推荐，一对多/多对多
joined 1次（JOIN 查询） 同步场景，数据量小
subquery 2次（主表1次 + 子查询1次） 复杂查询
noload 1次（不加载关联） 不需要关联数据时
