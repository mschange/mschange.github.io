Step 2：连接池参数详解

参数说明

参数 默认值 说明 建议值
pool_size 5 连接池中保持的连接数 10~20
max_overflow 10 超出 pool_size 后最多额外创建的连接数 10~30
pool_timeout 30 从连接池获取连接的超时时间（秒） 30
pool_recycle -1 连接回收时间（秒），-1 表示不回收 3600
pool_pre_ping False 获取连接前检测连接是否有效 True
echo False 是否输出 SQL 日志 开发 True，生产 False
echo_pool False 是否输出连接池日志 调试时 True

常见错误与排查

错误 原因 解决方案
Can't connect to MySQL server MySQL 未启动或连接信息错误 检查 MySQL 状态和 URL
Unknown database 数据库不存在 先创建数据库
MySQL has gone away 连接超时被 MySQL 断开 设置 pool_recycle 和 pool_pre_ping
PoolExceededError 连接池耗尽 增大 pool_size 和 max_overflow
MissingGreenlet 在异步代码中使用了同步操作 确保使用 AsyncSession 和 create_async_engine

关键要点总结

要点 说明
create_async_engine 创建异步引擎，管理连接池
pool_size 连接池保持的连接数
max_overflow 额外可创建的连接数
pool_recycle 连接回收时间，防止 MySQL 断连
pool_pre_ping 获取连接前检测有效性
async_sessionmaker 异步会话工厂
expire_on_commit=False commit 后属性不过期
get_db() yield 依赖，管理会话生命周期
startup 事件 应用启动时建表
shutdown 事件 应用关闭时释放连接池
